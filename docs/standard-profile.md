# Standard Profile Specification (Figma Frame 29)

## Overview
The Standard Profile is an agency-branded candidate presentation document customized for client review (e.g. `Aureva Capital — Standard Profile`).

## Content Sections
1. Candidate Identity: Name, Candidate Code, Location
2. Professional Headline: Tailored title summarizing candidate expertise
3. Professional Summary: Editable by recruiter to align candidate strengths with client mandate
4. Core Competencies: Selected key skills
5. Selected Experience Highlights: Curated work experience with company, title, duration, and key contributions
6. Education & Credentials: Degree and institution
7. Portfolio & Links: Verified public code/portfolio links

## Confidentiality Boundary
Original candidate records are never mutated when recruiters edit a Standard Profile. Profile edits are stored as versioned submission artifacts (`SubmissionProfileVersion`).
